# T391: Review Workspace Local Server Payload

## Task ID

T391

## Goal

Integrate the review workspace presentation payload with the existing local web
demo server.

T391 should expose a synthetic review workspace payload generated by the T389
presentation adapter through the local demo server shape, so the static review
panel can consume server-provided synthetic data rather than relying only on an
embedded fallback fixture. It must remain local-only, synthetic, non-sending,
non-mutating, and provider-free.

## Why Now

T390 added a static review workspace panel with a safe fallback fixture. T391
can now connect that panel to the existing local demo server payload flow while
preserving all M29 safety boundaries.
